# Beaver v Otter

A mobile-first educational web game about beavers, otters, river ecosystems and water quality.

## What is included

- Beaver and otter character paths
- Five interactive river challenges for each animal
- River-health and knowledge scoring
- Immediate educational feedback after each choice
- Learning sections covering habitat, food webs and water-quality fundamentals
- Responsive, keyboard-friendly interface
- Reduced-motion support
- Static HTML/CSS/JavaScript architecture suitable for GitHub Pages

## Run locally

Open `index.html` directly in a browser, or serve the repository with any static web server.

## Deployment

The project is designed to deploy from the repository root with GitHub Pages.
